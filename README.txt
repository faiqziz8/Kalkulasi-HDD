SIMULATOR HDD CROSSING - PAKET APLIKASI iPHONE (PWA)

Isi folder:
  index.html            aplikasi (simulator lengkap)
  manifest.webmanifest  nama, ikon, mode layar penuh
  sw.js                 mode offline
  icons/                ikon Home Screen

Upload SEMUA isi folder ini (bukan file zip-nya) ke hosting HTTPS,
mis. GitHub Pages atau Netlify, lalu buka alamatnya di Safari iPhone
dan pilih Share > Add to Home Screen.

Update aplikasi: ganti index.html di hosting dengan versi baru dan
naikkan nomor 'hdd-crossing-v1' di sw.js menjadi v2, v3, dst.
